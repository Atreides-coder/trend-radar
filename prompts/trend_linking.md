你在为一个中文短视频趋势栏目寻找"趋势"。下面有两份材料：今天的全部 Event（每个是一件具体的事），以及系统已经在跟踪的趋势列表。

你的任务是找出：**哪些不同的 Event，可能其实指向同一个更大的趋势？**

## 什么算一个趋势

趋势是由多件各自独立的事共同支持的一个方向。它是一个**假设**，不是事实：你在说"这几件事放在一起看，可能意味着……"。

好的趋势假设是具体的，能说出什么在变、往哪个方向变：

- "CD 收藏回潮"和"便携 MP3 播放器回潮"是两件不同的事，但可能共同指向：消费者开始重新购买专用的实体或离线媒体设备。
- "Apple 因 AI Agent 收紧系统权限"和"AI 应用开始要求更大的系统控制权"，可能共同指向：AI Agent 正在迫使操作系统重新设计权限体系。

不好的趋势假设：

- 太宽泛，什么都能装进去："AI 正在发展""科技改变生活"。
- 只是把同一家公司或同一个领域的事放在一起，说不出共同的方向。
- 只有一件事支持的新趋势。一件事是事件，不是趋势。

不要为了凑数而硬连。大部分 Event 不属于任何趋势，这是正常的。宁可少而准。

## 已有的趋势

如果今天的 Event 属于一个已经在跟踪的趋势，就归到它下面，不要另起一个新名字。名称不同但说的是同一个方向时也算同一个趋势，例如已有"AI 浏览器"，今天出现"浏览器 Agent"，应该归入已有趋势。

- 归入已有趋势：`existing_trend_id` 填那个趋势的 id。此时只有一个 Event 支持也可以。`trend_name` 沿用已有名称，或者在名称明显不再贴切时给出更好的写法。
- 新趋势：`existing_trend_id` 填 0，并且至少要有两个不同的 Event 支持。

## 每个趋势要写什么

- `trend_name`：中文，简短具体，不超过 20 个字。
- `aliases`：1–3 个别的叫法，包括常见的英文说法，用来在以后识别同一个趋势。
- `event_ids`：支持这个趋势的 Event 的 id。只能用输入里出现的 id。
- `hypothesis`：一到两句中文，说清楚这个假设：这些事放在一起，可能意味着什么正在发生变化。
- `confidence`：0–5 的整数，你对这个假设的把握。
  - 1：只是一个有趣的联想，支持很弱。
  - 3：两三件独立的事指向同一方向，值得继续观察。
  - 5：多件独立的事、多个独立来源清楚地指向同一方向。

一个 Event 最多属于两个趋势。没有找到任何趋势时，返回空列表。
